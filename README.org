#+TITLE: ortask — org-mode task CLI

=ortask.py= is a command-line tool for querying and editing TODO tasks
in org-mode files.  It operates on a =* Tasks= subtree, leaving the
rest of the file untouched.

Tasks use standard org-mode =TODO= / =DONE= keywords with stable IDs:

#+begin_example
,* Tasks
,** DONE t0001 Initialize LLMs in this directory
,*** DONE t0001.1 ChatGPT/codex
,*** DONE t0001.2 Gemini
,*** DONE t0001.3 Claude
,** TODO t0002 Build tool that updates this TODO list
#+end_example

* Quick start

#+begin_src sh
# list all tasks
./ortask.py list

# list only open tasks
./ortask.py list --state todo

# show a single task with body and subtasks
./ortask.py show t0001

# add a task
./ortask.py add "Research FooCorp"

# add a subtask
./ortask.py add "Check Glassdoor reviews" --parent t0003

# mark a task done
./ortask.py done t0002

# reopen a task
./ortask.py open t0002

# open the interactive task menu for the local task file
./ortask.py -i

# check for ID problems (dry run)
./ortask.py repair --dry-run

# fix ID problems
./ortask.py repair
#+end_src

By default, =ortask.py= walks upward from the current directory looking for
=task.org=, then exactly one =*.task.org=, then legacy names such as
=TODO.org=, =todo.org=, and =tasks.org=. Use =--file= or the =ORTASK_FILE=
env var to override. Ambiguous matches stop with an error instead of guessing.

* Shell alias

For daily use, alias =ortask.py= as =ort=:

#+begin_src sh
alias ort='/path/to/ortask.py'
#+end_src

Then: =ort list=, =ort add "Do the thing"=, =ort done t0004=, =ort -i=.

* Bash completion

For command and option completion, source the bundled completion script:

#+begin_src sh
source /path/to/ortask/misc/ortask-completion.bash
#+end_src

It registers completion for =ortask.py=, =./ortask.py=, and =ort=. After
sourcing it, typing =ortask.py ad<Tab>= or =ort ad<Tab>= completes to =add=.
A Debian package can install the same file under
=/usr/share/bash-completion/completions/=.

* Requirements

Python 3.10+ (standard library only, no dependencies).
